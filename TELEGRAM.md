# Приватні канали через ваш Telegram

Сайт сам читає публічні канали. Пральні машини, холодильники, плити й духові шафи
лежать у приватних каналах, тож їх сайт читає через ваш акаунт Telegram.
Налаштувати треба один раз, приблизно 10 хвилин.

## 1. Отримати api_id і api_hash

1. Відкрийте https://my.telegram.org і увійдіть своїм номером телефону
   (код прийде в Telegram).
2. Натисніть **API development tools**.
3. Заповніть: App title: `Catalog site`, Short name: `catalogsite`,
   Platform: `Desktop`. Решту можна не заповнювати. Натисніть **Create application**.
   Якщо бачите «ERROR», вимкніть VPN і спробуйте ще раз.
4. На сторінці будуть **App api_id** (число) і **App api_hash** (довгий рядок).
   Не закривайте цю сторінку.

## 2. Отримати рядок входу (TG_SESSION)

1. На Mac відкрийте програму **Термінал** (Cmd+Пробіл → «Термінал»).
2. Вставте цю команду і натисніть Enter:

   ```
   python3 -c "$(curl -fsSL https://raw.githubusercontent.com/defiloft/techika-catalog/main/scripts/tg_login.py)"
   ```

   Якщо Mac запропонує встановити «інструменти розробника», погодьтеся і
   після встановлення запустіть команду ще раз.
3. Введіть api_id, api_hash, свій номер телефону (у форматі +380…) і код,
   який прийде в Telegram. Якщо стоїть хмарний пароль, введіть і його.
4. Коли побачите «Готово», рядок входу вже скопійовано в буфер обміну.

## 3. Додати три секрети в GitHub

Відкрийте https://github.com/defiloft/techika-catalog/settings/secrets/actions
і тричі натисніть **New repository secret**:

| Name | Secret |
|---|---|
| `TG_SESSION` | вставте з буфера (Cmd+V), одразу після кроку 2 |
| `TG_API_ID` | число api_id |
| `TG_API_HASH` | рядок api_hash |

Потім відкрийте вкладку **Actions → Update products → Run workflow**, щоб не
чекати 30 хвилин. Перший запуск довший: сайт завантажує фото товарів.

## Що варто знати

- Ці три значення нікому не надсилайте, зокрема в чат. З ними можна читати ваш
  Telegram. У GitHub Secrets їх ніхто не бачить, навіть у логах.
- Сайт тільки читає канали. Якщо ви ще не підписані на якийсь приватний канал
  із посилань, акаунт сам у нього вступить.
- У Telegram → Налаштування → Пристрої з'явиться «Сайт-каталог (GitHub)».
  Якщо його завершити, сайт перестане бачити приватні канали (публічні працюють
  далі). Тоді повторіть крок 2 і оновіть `TG_SESSION`.
- Telegram не любить автоматичне читання з особистих акаунтів, якщо воно надто
  часте. Сайт читає спокійно (раз на 30 хвилин), але повністю ризик блокування
  виключити не можна.
- Нові приватні канали підхоплюються самі, якщо посилання-запрошення на них
  опубліковано в одному з публічних каналів магазину.
